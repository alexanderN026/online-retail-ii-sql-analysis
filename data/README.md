# Data

The dataset is not included in this repository, because it is large and can be downloaded for free.

1. Download `online_retail_II.xlsx` from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii).
2. Save it in this folder.

When you run the notebook, it also creates the database file `Online Retail II_Dataset.duckdb` here.

Dataset: Online Retail II by Daqing Chen, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
